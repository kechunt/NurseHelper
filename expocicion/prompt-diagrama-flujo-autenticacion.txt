[INICIO PROMPT]

Genera un diagrama de secuencia (UML o Mermaid sequenceDiagram) para el flujo
de autenticación en NurseHelper.

PARTICIPANTES
- Usuario
- LoginComponent (Angular)
- AuthService (frontend)
- authInterceptor (HTTP)
- authGuard (router)
- POST /api/auth/login (Express)
- auth.controller + User entity
- MySQL
- Dashboard según rol (Admin / Nurse / Pharmacy / Supervisor)

FLUJO 1: LOGIN EXITOSO
1. Usuario ingresa credenciales en /login
2. AuthService → POST /api/auth/login (rate limit en auth)
3. Backend valida bcrypt, genera JWT (userId, role)
4. Frontend guarda token, navega a defaultDashboardPath(role)
5. Ejemplo: nurse → /nurse-dashboard

FLUJO 2: PETICIÓN AUTENTICADA
1. Componente llama API (ej. GET /api/nurse/tasks/today)
2. authInterceptor añade Authorization: Bearer <token>
3. loadingInterceptor muestra spinner global
4. auth.middleware verifica JWT, carga User activo
5. role.middleware valida permiso del endpoint
6. Respuesta JSON al componente

FLUJO 3: TOKEN INVÁLIDO O EXPIRADO
1. API responde 401
2. authInterceptor hace logout y redirige a /login

FLUJO 4: GUARD EN RUTA
1. Usuario intenta /admin sin rol admin
2. adminGuard redirige a su dashboard o login

REQUISITOS
- Mermaid sequenceDiagram con autonumber opcional
- Etiquetas en ESPAÑOL
- Fondo claro; máximo 8-10 pasos por flujo o 3 flujos separados con notas
- Incluir nota: «La seguridad definitiva está en el backend»
