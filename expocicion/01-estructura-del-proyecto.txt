1. VISIÓN GENERAL DEL MONOREPO
================================================================================

El repositorio raíz orquesta dos aplicaciones independientes (backend y frontend)
más scripts de desarrollo. No usa workspaces npm formales; el package.json raíz
delega con npm run --prefix o scripts en scripts/.

Ruta base: NurseHelper/

5. SCRIPTS NPM CLAVE (RAÍZ)
================================================================================

  Script              | Acción
  --------------------|--------------------------------------------------
  npm run dev         | Backend + frontend en paralelo (start-dev.js)
  npm run build       | Compila backend (tsc) y frontend (ng build)
  npm run test        | Tests backend + frontend
  npm run lint        | ESLint en ambos paquetes
  npm run install:all | npm install en raíz, backend y frontend
  npm run migration:run | Ejecuta migraciones TypeORM
  npm run tunnel      | Túnel ngrok para demo remota

Backend (backend/package.json):
  dev, build, start, test:unit, test:integration, migration:*

Frontend (frontend/package.json):
  start (ng serve), build, test (Karma), e2e (Playwright), lint

8. DESPLIEGUE Y ARTEFACTOS
================================================================================

  - Frontend: Vercel (frontend/vercel.json, build con write-api-url.mjs)
  - Backend: Railway (railway.json, nixpacks.toml, Procfile) u host Node
  - CI: .github/workflows/ci-cd.yml en push/PR a main y develop
  - Health checks: GET /health, /health/ready, /health/live


9. PARA LA EXPOSICIÓN ORAL (1 MINUTO)
================================================================================

  - Explica que es un monorepo con dos apps y scripts de arranque unificado.
  - Muestra backend/src como capas claras: routes → controllers → services → entities.
  - Muestra frontend/src/app/components separado por rol (admin, nurse, pharmacy).
  - Menciona migraciones TypeORM (no sync automático) como buena práctica en producción.
  - Cierra con npm run dev y los puertos 4200 / 3000 para la demo en vivo.
