1. QUÉ ES NURSEHELPER
================================================================================

NurseHelper es un sistema de gestión clínica orientado a centros de cuidado
(residencias, clínicas, hospitales pequeños). Centraliza en una sola aplicación
web las operaciones de:

  - Administración (usuarios, áreas, camas, pacientes, horarios)
  - Supervisión (coordinación de turnos, reportes globales)
  - Enfermería (tareas del día, medicación, camas, notas clínicas, entrega)
  - Farmacia (solicitudes, inventario, asistencia de turno)

El proyecto es un monorepo con frontend SPA (Angular 20) y API REST (Express +
TypeORM + MySQL 8).


2. PROBLEMA QUE RESUELVE
================================================================================

  - Evita planillas dispersas y errores en la administración de medicación.
  - Da visibilidad del cumplimiento de tareas y horarios por paciente y periodo.
  - Separa responsabilidades por rol (cada usuario ve solo lo que le corresponde).
  - Conecta enfermería con farmacia mediante solicitudes y entregas trazables.
  - Permite coordinación entre turnos (notas de handover / coordinación).

4. STACK TECNOLÓGICO (RESUMEN)
================================================================================

  Capa          | Tecnología principal
  --------------|--------------------------------------------------
  Frontend      | Angular 20, TypeScript 5.9, RxJS, Zone.js
  UI            | CSS neumórfico propio, Bootstrap Icons
  Backend       | Node.js 20+, Express 4, TypeScript 5.3
  Base de datos | MySQL 8, TypeORM 0.3 (migraciones, sin sync auto)
  Auth          | JWT (Bearer), bcrypt en contraseñas
  Tests FE      | Karma/Jasmine (unit), Playwright (E2E)
  Tests BE      | Jest (unit + integration con Supertest)
  CI            | GitHub Actions (.github/workflows/ci-cd.yml)
  Despliegue    | Vercel (frontend), Railway u host Node (backend)


5. CÓMO ARRANCAR EL PROYECTO (DESARROLLO)
================================================================================

  1. npm run install:all
  2. cp backend/.env.example backend/.env.local  (editar MySQL y JWT_SECRET)
  3. npm run migration:run
  4. npm run dev

URLs locales:
  - Frontend: http://localhost:4200
  - API:      http://localhost:3000
  - Health:   http://localhost:3000/health

Scripts útiles en la raíz: build, test, lint, tunnel (ngrok para demos remotas).
