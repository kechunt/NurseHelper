Nota de entrega

Nota de paso de turno para tu área: pacientes a vigilar, incidencias, pendientes para quien releva, etc.

Se guarda una nota por área, por día y por turno (mañana / tarde / noche). Las enfermeras del mismo área eligen fecha y franja para leer o actualizar. No aparece en otra pantalla; es un registro compartido al paso de turno.
